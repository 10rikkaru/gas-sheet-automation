# 受注シートのチェックと月次集計を自動化(Google Apps Script)

Googleスプレッドシートの「受注」シートを点検し、問題のある行に色を付け、問題の一覧と、月別・担当者別の売上集計を別シートに書き出すサンプルです。メニューから1クリック、または毎朝の自動実行で動きます。

> データはすべてダミーです。

## できること

| 機能 | 内容 |
|---|---|
| 入力チェック | 必須項目の空欄、受注番号の重複、数量・単価の誤り(文字、0以下、小数の数量)、存在しない日付を見つける |
| 色付け | 問題のある行を薄い赤にする(実行のたびに付け直す) |
| チェック結果 | 「チェック結果」シートに、行番号・項目・内容を一覧で書き出す |
| 月次集計 | 問題のない行だけを、月別・担当者別に件数と金額で集計し、「月次集計」シートに書き出す |
| 自動実行 | メニューから「毎朝8時に自動実行する」を選ぶと、毎朝実行される |

## 動作例

`sample/orders.csv`(9件、うち3件に問題を混ぜてある)での結果です。`npm run demo` で同じものを表示できます。

**チェック結果**

| 行 | 項目 | 内容 |
|---|---|---|
| 5 | 受注番号 | 3行目と重複しています |
| 6 | 顧客名 | 空欄です |
| 7 | 数量 | 数値ではありません |

**月次集計**(問題のある3行を除く)

| 月 | 担当者 | 件数 | 金額 |
|---|---|---|---|
| 2026-10 | 佐藤 | 2 | 8,100 |
| 2026-10 | 鈴木 | 1 | 17,600 |
| 2026-11 | 佐藤 | 1 | 2,400 |
| 2026-11 | 鈴木 | 1 | 1,350 |
| 2026-11 | 高橋 | 1 | 8,800 |

## 確認したケース(自動テスト 10件)

`npm test` で実行できます(Node.js 18 以上、外部ライブラリ不要)。

| # | ケース | 期待する結果 |
|---|---|---|
| 1 | 正常なデータ | 問題なし |
| 2 | データが0件 | エラーにならず、結果も0件 |
| 3 | 空行が混ざっている | 空行は無視する |
| 4 | 必須項目の空欄 | 項目ごとに報告する |
| 5 | 受注番号の重複(前後の空白違いも含む) | 2件目以降を、最初の行番号つきで報告する |
| 6 | 数量・単価が文字、0以下、小数の数量 | それぞれ報告する |
| 7 | 「1,200」のようなカンマ付きの数値、「2026/10/05」のような文字列の日付 | 正しく読む |
| 8 | 存在しない日付(2026-02-30) | 誤りとして報告する |
| 9 | 複数の月・担当者 | 月→担当者の順に集計する |
| 10 | 問題のある行 | 集計に含めない |

## 構成

```
src/core.js      チェックと集計のロジック(Apps Script と Node.js の両方で動く)
src/main.js      スプレッドシートの読み書き、メニュー、自動実行(Apps Script 専用)
test/            core.js の自動テスト
sample/          ダミーの受注データ
appsscript.json  Apps Script の設定(タイムゾーン、必要な権限を最小限に)
```

ロジックとシートの読み書きを分けているので、シートを使わずにロジックだけをテストできます。列の並びが変わったときは `src/core.js` の `COLUMNS` だけを直せば済みます。

## スプレッドシートでの使い方

1. 新しいスプレッドシートを作り、シート名を「受注」にして `sample/orders.csv` を貼り付ける
2. 「拡張機能」→「Apps Script」を開き、`core.js` と `main.js` の中身をそれぞれ新しいファイルに貼り付けて保存する
3. スプレッドシートを開き直すと、メニューに「自動化」が出る
4. 「自動化」→「チェックと集計を実行」(初回は権限の確認が出ます)

`clasp`(Apps Script のコマンドラインツール)を使う場合は、このフォルダをそのままプッシュできます。
